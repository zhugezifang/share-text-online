# share text online
> Free, secure, instant text sharing online — no login, no installation

## Overview
[share text](https://share-text.org/) is a **100% free online text sharing tool** that lets you create, format, and share text content instantly via secure links and QR codes. It requires no registration, no software installation, and works across all devices and modern browsers.

## Key Features
- **No Login/Registration**: Use immediately without signing up or providing personal data
- **Rich Text Formatting**: Support for bold, italic, code blocks, and more
- **Flexible Expiration**: Set availability from 1 day up to 3 months
- **Secure Links & QR Codes**: Safe, private sharing for notes, code snippets, and messages
- **Cross‑Platform**: Works on Windows, Mac, Linux, Android, iOS
- **Mobile‑Optimized**: Touch-friendly interface for phones and tablets
- **Built‑in Spell Check**: Ensure error‑free content before sharing
- **Dark Mode Support**: Comfortable viewing in low‑light environments
- **100% Free**: No hidden fees, no premium tiers
- **Browser‑Only**: No downloads or installations needed

## How to Use
1. Paste or type your text into the editor
2. Format content using the built‑in styling tools
3. Set an expiration time (1 day – 3 months)
4. Click **Share Text Online** to generate a link and QR code
5. Share the link or scan the QR code to access your text

## Security & Privacy
- Content is accessible **only via the unique secure link**
- Shared text is automatically deleted after expiration
- No permanent storage or public indexing
- Suitable for temporary notes, code snippets, and private sharing
